# Horizon RPG v15 — Core Cleanup

This build removes the following player-facing systems before the deepening pass:
- NPCs, NPC dialogue/relationships, lore/hidden NPC quests
- Story and story choices
- Living-world clock/weather/rumors/NPC schedules
- Housing and player/world construction
- Life-path selection UI
- Advanced faction reputation editing and diplomacy
- Mysteries, anomalies, and artificial world-event contribution systems
- Manual world-memory commands
- Misleading RPG completion audit

Quest journal remains, but story-chain quests are removed.
Core RPG systems remain the focus for the next deepening build.

No new gameplay systems were added in this cleanup pass.
