# Horizon RPG v14.1 — Command Stability & Help

## Problems addressed
- Some RPG prefix commands could remain pending when an underlying database/API operation took too long.
- Rapidly sending multiple RPG commands could overlap operations for the same player.
- `!rpg help` only documented a subset of the RPG command surface.

## Changes
- 30-second hard timeout for RPG prefix command execution.
- Per-guild/per-player RPG command lock.
- Timeout logging and user-facing recovery message.
- Complete paginated `!rpg help` generated from the registered command tree, including nested commands and aliases.
- Duplicate Endgame panel entry removed.

## Testing
- `python -m py_compile bot.py rpg.py` passed.
- Static RPG command/alias collision audit passed.
- No database reset or OP command changes.
